Solid-State Nanopore Chips

Built on KTH cleanroom infrastructure, we manufacture ultrathin, geometry-tunable solid-state nanopore chips.

Key Features

  • Pore diameter range: 10-100nm
  • HfO2 membrane（chemically stable）
  • 5nm pore length（optional length available）
  • Single pore design (optional array available)
  • 2.5mm * 2.5mm * 300μm（optional size available）

Ready-to-Use Microfluidic Flowcells

Each nanopore chip is packaged as a ready-to-use flow cell, enabling researchers to plug the chips into existing electronics and microfluidics.

Key Features

  • Standard microfluidic interfaces
  • Gasket for leak-proof seal
  • Clamp and use
  • Customized microfluidic configurations
